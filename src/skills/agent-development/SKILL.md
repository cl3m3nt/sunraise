# Agent Development

## Quick Start

When providing guidance:

1. Check which agent harness scope is developed
2. Use appropriate agent harness skill

## Provide guidance
1. Ask which scope of agent harness to be develop
2. Follow with the possible scope: LLM, Tools, Skills, MCP, Loop, Session, Memory, 
3. Forward to specific scope guidance details

## Agent scope
1. LLM: Anthropic, Google, OpenAI, Mistral, OpenLLM
2. Tools: get_weather, get_current_time, read_skill
3. Skills: skills to be added to agent
4. MCP: Model Context Protocol
5. Loop: The ReAct loop the agent can use to reason
6. Session: The user session created when using sunraise
7. Memory: The summary, fact saved for long term
